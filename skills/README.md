# Skills

Nothing in this directory is copied from upstream.

`manifest.yaml` pins mattpocock/skills tag v1.3.2. Install the official plugin
instead of copying files:

```bash
claude plugin install mattpocock-skills@claude-plugins-official
codex plugin add mattpocock-skills@mattpocock
```

`own/` is reserved for pipeline-authored skills. It is empty in the scaffold.
See `NOTICE` for the MIT attribution.
